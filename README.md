## 🛠 Compilation Instructions

### 1. Using Tectonic (Recommended)
```bash
# Vietnamese version
tectonic resume.tex

# English version
tectonic resume_en.tex
```

### 2. Using XeLaTeX / pdfLaTeX
```bash
xelatex resume_en.tex
# or
pdflatex resume_en.tex
```

### 3. Overleaf
Upload `resume_en.tex` (or `resume.tex`) and `anh-chan-dung.jpg` to [Overleaf](https://www.overleaf.com/) and click **Recompile**.
