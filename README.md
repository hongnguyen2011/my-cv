## 🛠 Compilation Instructions

### 1. Using Tectonic (Recommended)
```bash
tectonic resume.tex
```

### 2. Using XeLaTeX / pdfLaTeX
```bash
xelatex resume.tex
# or
pdflatex resume.tex
```

### 3. Overleaf
Upload `resume.tex` and `anh-chan-dung.jpg` to [Overleaf](https://www.overleaf.com/) and click **Recompile**.
